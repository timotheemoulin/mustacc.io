# mustacc.io

Page d'accueil de [mustacc.io](https://mustacc.io), le labo perso de Tim : outils, recherches, tests et POC, servis serrés.

Le nom est un clin d'œil au petit homme à moustache de Bialetti. Le logo aussi.

## Contenu

- `index.html` : la landing, un seul fichier, HTML + CSS inline, aucune dépendance (les polices viennent de Google Fonts).

## Projets

Chaque projet vit dans son propre sous-dossier et s'ouvre dans un nouvel onglet depuis le menu de la home.

| Chemin | Projet | Source |
|---|---|---|
| `/magellan/` | Vénus en 3D depuis les données radar Magellan | [magellan-venus](https://github.com/timotheemoulin/magellan-venus) |
| `/mont-destin/` | Scrollytelling de la Communauté à travers la Terre du Milieu | [terredumilieu](https://github.com/timotheemoulin/terredumilieu) |
